# Source tables

| Archive | Contents |
| --- | --- |
| [Data S1: measurements](Data_S1_measurements.zip) | Within-source repeatability, cross-source concordance, matching and exclusion records, and response composition |
| [Data S2: predictions](Data_S2_predictions.zip) | Baseline and component scores, drug-to-interaction diagnostics, cross-plate outcomes, and exploratory results with controls |

Each archive contains `CONTENTS.json` with member paths and checksums.
The [analysis indexes](../README.md) identify relevant files without requiring
expression-data downloads. Archive member identifiers preserve correspondence with the source analyses.

Plotting inputs are in [figure_inputs/](../figure_inputs/); plotting code and
[captions](../../code/common/docs/FIGURE_LEGENDS.json) are supplied separately.
